# Eastside Library Study Rooms

A small booking app for a library's study room hours. Course starter app for SDC332.

- `app/`: the app code
- `tests/`: the tests (`python -m unittest discover -s tests -v`)
- `scripts/package.py`: builds the release package in `dist/`
- `scripts/release_check.py`: prints the release's settings after a deploy
- `VERSION`: the release number
- `course/card.json`: your team card (made by the course kit)
